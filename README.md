# Andreo AI by KAI

Always-online AI assistant running on Render.com free tier.

## API Endpoints

- `POST /chat` - Chat with Andreo
- `POST /remember` - Store memory
- `POST /recall` - Search memories
- `GET /status` - System status

## Deploy

1. Push to GitHub
2. Connect to Render.com
3. Done! 24/7 AI online.
